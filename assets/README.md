# 자산 아카이브

포트폴리오와 학습 문서에서 사용하는 이미지를 용도별로 정리한 폴더입니다. 이미지 파일만 나열하지 않고, 각 하위 README에서 이미지의 목적과 연결된 본문을 함께 확인할 수 있습니다.

| 하위 폴더 | 보관 내용 | 확인할 문서 |
| --- | --- | --- |
| [`products/`](./products/README.md) | UPS·ESS·OBC 공개 제품 예시 이미지 | [제품 이미지 인덱스](./products/README.md) |
| [`labs/`](./labs/README.md) | 제어 알고리즘, DC-DC, PFC, DAB·SRDAB, LLC의 개요·화면·수식 이미지 | [랩 화면 인덱스](./labs/README.md) |
| [`portfolio/`](./portfolio/README.md) | ESS 계통연계와 UPS 검증 사례의 공개용 이미지 및 설명 | [검증 포트폴리오](./portfolio/README.md) |

## 사용 기준

- 제품 이미지는 시스템을 이해하기 위한 공개 예시이며, 업무 수행 제품이나 고객 정보를 의미하지 않습니다.
- 랩 이미지는 학습 주제의 화면·수식 설명을 위한 자료입니다. 원본 모델, 제어 파라미터, 시험 로그는 포함하지 않습니다.
- 검증 사례 이미지는 공개 범위를 지키기 위해 필요한 부분만 남긴 자료입니다. 표준 적합성은 적용 판본과 시험 조건을 함께 확인해야 합니다.
