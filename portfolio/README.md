# 전력변환 시스템 포트폴리오

세 분야는 서로 다른 제품을 다루지만, 입력 전원을 원하는 형태로 변환하고 보호 조건 안에서 안정적으로 전달한다는 공통점을 가집니다. 각 문서는 공개 가능한 시스템 구조와 검증 관점만 정리합니다.

| 분야 | 핵심 전력 경로 | 문서 |
| --- | --- | --- |
| UPS | 상용 AC → 정류/DC Link → 인버터 → 중요 부하 | [UPS 읽기](./UPS/README.md) |
| ESS | 배터리 ↔ PCS ↔ 계통·부하 | [ESS 읽기](./ESS/README.md) |
| OBC | AC 입력 → PFC → 절연 DC-DC → 고전압 배터리 | [OBC 읽기](./OBC/README.md) |

각 폴더의 `README.md`는 GitHub에서 바로 읽는 문서이고, `index.html`은 구성도와 제품 이미지를 포함한 HTML 페이지 원본입니다.
