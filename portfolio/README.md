# 공개 포트폴리오

세 사례는 같은 형식으로 읽습니다. 먼저 `README.md`에서 시스템 경계와 사례의 공개 범위를 확인하고, 이어서 `CASE_STUDY.md`에서 문제·구성·확인 항목·공개 증거를 봅니다. 이미지는 공용 폴더가 아니라 해당 사례의 `assets/`에 둡니다.

| 번호 | 사례 | 사례 문서 | 화면형 문서 | 공개 작업 캡처 |
| ---: | --- | --- | --- | --- |
| 01 | UPS | [README](./UPS/README.md) · [Case study](./UPS/CASE_STUDY.md) | [HTML](./UPS/index.html) | 병렬전류·부하 과도·Hot Swap 파형 |
| 02 | ESS | [README](./ESS/README.md) · [Case study](./ESS/CASE_STUDY.md) | [HTML](./ESS/index.html) | 충방전·Ramp Rate·Ride-Through·Anti-Islanding 화면 |
| 03 | OBC | [README](./OBC/README.md) · [Case study](./OBC/CASE_STUDY.md) | [HTML](./OBC/index.html) | PFC·DC/DC·제어 학습 화면. 실제 차량 시험 캡처는 아님. |

사례 문서에는 외부에 공개 가능한 범위의 시스템 설명과 검증 관점만 수록합니다. 세부 회로, 제어 게인, 고객·제품 식별 정보, 원본 시험 로그는 포함하지 않습니다.

각 사례의 `CASE_STUDY.md`와 HTML에는 읽는 데 필요한 공개 캡처를 직접 넣었습니다. 캡처의 출처와 범위를 문서 안에 표시해, 설명용 제품 이미지·공개 작업 증거·학습 화면을 서로 혼동하지 않도록 했습니다.
