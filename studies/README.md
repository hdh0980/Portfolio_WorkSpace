## 자료 상태를 읽는 기준

- `본문·예제 정리됨`: 과목 또는 프로젝트 README에서 세부 단원·자료·검증 기록을 확인할 수 있습니다.
- `학습 본문 작성 전`: 폴더명과 분류만 정리된 상태입니다. 아직 설명·수식·예제를 추가하지 않았습니다.
- 새 학습 본문은 참고문헌, 범위, 검증 방법을 먼저 확인한 뒤에 추가합니다.

## 공개 원칙

학습 문서에는 참고자료를 기반으로 직접 정리한 내용만 기록합니다. 회사·고객 정보, 비공개 회로와 파라미터, 원본 시험 로그는 포함하지 않습니다.
