# 산업동향 파악

전력수급·계통운영·에너지저장·전기차 보급 관련 공개 자료를 매달 읽고, UPS·ESS·OBC 쪽에서 볼 점을 적은 메모입니다. 월마다 그 달 자료와 세 제품을 잇는 도식을 하나씩 넣었습니다.

## 보는 자료

| 분야 | 읽는 이유 | 관련 사례 |
| --- | --- | --- |
| 전력수요·계통운영 | 피크, 가격, 공급 여건이 전력 품질·복원력 요구로 이어진다 | UPS · ESS |
| 저장장치·유연성 | 재생에너지 비중, 출력제어, 저장장치 시장 제도 | ESS |
| 전동화·충전 | 전기차 보급, 충전 인프라, 계통 연계가 OBC 사용 조건을 바꾼다 | OBC |
| 중요부하 | 데이터센터처럼 정전 허용도가 낮은 부하 증가 | UPS |

월별 전력시장 수치는 전력거래소 운영실적 `속보` 기준이라 최종 정산값과 다를 수 있고, 실적 월과 공표일이 다릅니다.
