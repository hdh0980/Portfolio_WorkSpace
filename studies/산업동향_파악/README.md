# 산업동향 파악

전력변환 엔지니어가 UPS, ESS, OBC를 볼 때 필요한 외부 환경을 월 단위로 기록하는 폴더입니다. 제품·고객·회사 내부 정보가 아니라, 전력수급·계통운영·에너지저장·전기차 보급과 같이 공개된 자료에서 확인할 수 있는 변화만 다룹니다.

각 월 문서에는 두 개의 자체 도식을 함께 배치했습니다. 첫 번째 그림은 그 달의 공개 산업 신호를 UPS·ESS·OBC의 설계·검증 질문으로 연결하고, 두 번째 그림은 관찰 사실·기술적 해석·다음 확인 항목의 경계를 보여 줍니다. 그림은 원문 수치나 타사의 도표를 복제한 것이 아니며, 각 문서에 연결한 공식 참고자료의 범위를 정리한 도식입니다.

## 조사 범위

| 관점 | 읽는 이유 | 연결되는 포트폴리오 |
| --- | --- | --- |
| 전력수요·계통운영 | 계통 피크, 가격, 공급 여건은 전력 품질과 복원력 논의를 만드는 배경이다. | UPS · ESS |
| 저장장치·유연성 | 태양광·풍력 비중 증가, 출력제어, 피크 대응과 저장장치 시장 제도를 함께 본다. | ESS |
| 전동화·충전 | 전기차 보급, 충전 인프라, 전력망 연계는 OBC의 사용 환경을 바꾼다. | OBC |
| 중요부하 | 데이터센터·산업 설비처럼 정전 허용도가 낮은 부하 증가는 UPS의 요구 조건과 연결된다. | UPS |

## 읽는 방법

각 월 문서는 세 층으로 작성했습니다.

1. **관찰 사실**은 원문에 나온 수치·정책·발표 시점만 적습니다.
2. **기술적 해석**은 그 사실이 UPS·ESS·OBC의 설계·검증 관점에서 왜 중요한지 연결합니다. 시장 규모나 수주 가능성을 단정하지 않습니다.
3. **다음 확인 항목**은 다음 달에 같은 기준으로 다시 확인할 지표입니다. 공개 자료만으로 답할 수 없는 내용은 ‘확인 불가’로 남깁니다.

월별 전력시장 수치는 전력거래소가 뒤늦게 공표한 `속보`를 기준으로 합니다. 따라서 ‘해당 월의 실적’과 ‘공표 일자’를 구분해서 읽어야 하며, 속보 수치는 최종 정산값과 다를 수 있습니다.
