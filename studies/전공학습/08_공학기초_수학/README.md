# 공학기초·수학

제어·회로·모델링에서 반복해서 쓰는 수학과 기계공학 기초를 별도 인덱스로 둡니다. 현재는 하위 범위를 분리한 상태이며, 학습 본문은 작성 전입니다.

| 하위 페이지 | 정리할 범위 | 현재 상태 |
| --- | --- | --- |
| [선형대수](./01_선형대수/README.md) | 벡터·행렬·고유값 등 공학 계산에 쓰는 기초 | 학습 본문 작성 전 |
| [기계공학 기초](./02_기계공학_기초/README.md) | 운동·힘·에너지 등 전동화·구동계 이해에 필요한 기초 | 학습 본문 작성 전 |

학습 자료는 문제 풀이 결과만 나열하지 않고, 적용한 정의·식의 출처와 계산 조건을 함께 남깁니다.
