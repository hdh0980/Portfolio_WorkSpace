# 전동화 시스템

전동화 시스템은 차량 전체 관점의 기술과 차량 전자제어 관점의 구조를 구분해 정리합니다. 현재는 두 하위 영역의 인덱스만 준비되어 있고, 학습 본문은 작성 전입니다.

| 하위 페이지 | 정리할 범위 | 현재 상태 |
| --- | --- | --- |
| [전기차 기술](./01_전기차_기술/README.md) | 전력원, 구동·충전·열관리·에너지 흐름을 연결해 보는 시스템 관점 | 학습 본문 작성 전 |
| [차량 전자제어](./02_차량_전자제어/README.md) | 제어기, 통신, 센서·액추에이터, 상태 진단의 연결 | 학습 본문 작성 전 |

새 학습 자료는 공개 기술 문서와 참고문헌을 명시하고, 제품·고객 식별 정보나 비공개 통신·제어 데이터는 제외합니다.
