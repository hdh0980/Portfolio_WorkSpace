# 전공학습

전력전자·제어·전동화를 공부하면서 정리한 노트입니다. 선수 관계 순서로 폴더를 나눴습니다.

```text
전기전자 핵심기초
  → 제어시스템 설계
  → 모델링·시뮬레이션
  → 전력변환 회로
  → 모터구동·센서
  → 전동화 시스템
```
