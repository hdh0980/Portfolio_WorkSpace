# 기술동향 리서치

이 폴더는 학습 본문과 달리, 공개 기술 자료를 읽고 변화·적용 범위·확인할 질문을 남기는 리서치 인덱스입니다. 현재는 기술뉴스와 공학상식으로 분류만 준비되어 있으며, 개별 리서치 본문은 작성 전입니다.

| 하위 페이지 | 정리할 자료 | 현재 상태 |
| --- | --- | --- |
| [기술뉴스](./01_기술뉴스/README.md) | 발표·논문·제품·표준 업데이트를 원문 출처와 함께 보는 기록 | 리서치 본문 작성 전 |
| [공학상식](./02_공학상식/README.md) | 기초 개념을 다시 확인할 때 쓰는 짧은 출처 기반 메모 | 리서치 본문 작성 전 |

## 리서치 기록 기준

날짜, 원문 URL, 문서 발행 주체, 확인한 사실과 해석을 구분합니다. 기사나 홍보 문구만으로 성능·표준 적합성을 단정하지 않으며, 회사 내부 사례는 기록하지 않습니다.
