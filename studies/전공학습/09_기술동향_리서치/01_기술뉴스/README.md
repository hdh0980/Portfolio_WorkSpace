# 기술뉴스

공개 발표, 논문, 제품 문서, 표준 업데이트를 출처와 날짜 중심으로 정리하기 위한 하위 페이지입니다. 현재는 분류 구조만 있고 개별 리서치 기록은 아직 추가하지 않았습니다.

## 기록할 형식

| 항목 | 남길 내용 |
| --- | --- |
| 출처 | 원문 URL, 발행 주체, 발행 또는 확인 날짜 |
| 주제 | 무엇이 바뀌었는지와 적용 대상 |
| 확인한 사실 | 원문에서 직접 확인한 정보 |
| 검토 메모 | 추가로 확인할 기술적 질문과 한계 |

게시 전에는 원문이 현재도 접근 가능한지 다시 확인합니다.
