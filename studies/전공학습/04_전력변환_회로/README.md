# 전력변환 회로

전력변환 회로 학습은 전력 흐름의 방향과 변환 단계에 따라 DC/DC 컨버터와 DC/AC 인버터로 나누었습니다. 현재는 하위 주제의 위치와 작성 기준만 정리한 상태입니다.

| 하위 페이지 | 정리할 범위 | 현재 상태 |
| --- | --- | --- |
| [DC/DC Converter](./01_DC_DC_Converter/README.md) | DC 전압 변환, 전력 흐름, 소자 스트레스, 제어·검증 자료 | 학습 본문 작성 전 |
| [DC/AC Inverter](./02_DC_AC_Inverter/README.md) | DC-AC 변환, 출력 품질, 계통·부하 조건, 제어·검증 자료 | 학습 본문 작성 전 |

## 작성 원칙

각 주제는 참고문헌을 먼저 정하고 `회로 또는 토폴로지 → 동작 조건 → 수식 근거 → 파형 또는 계산 검증 → 학습 기록` 순서로 작성합니다. 실제 제품 회로, 제어 파라미터, 사내 시험 자료는 기록하지 않습니다.
