# 모터구동·제어

이 폴더는 모터, 인버터, 센서, 제어기가 하나의 구동계로 연결되는 학습 주제를 정리하기 위한 영역입니다. 현재는 폴더 구조만 준비되어 있고 학습 본문은 작성하지 않았습니다.

## 자료를 추가할 때의 구성

| 구분 | 기록할 내용 |
| --- | --- |
| 대상 시스템 | 모터 종류, 전력변환 단계, 센싱 범위 |
| 제어 목적 | 속도·토크·전류 등 확인하려는 제어량 |
| 근거 자료 | 교재·논문·데이터시트 등 참고문헌 |
| 검증 | 계산, 모델, 시뮬레이션, 파형 중 적용 가능한 확인 방법 |

대상 모터와 참고문헌, 검증 방법을 확인한 뒤에만 학습 본문을 추가합니다.
