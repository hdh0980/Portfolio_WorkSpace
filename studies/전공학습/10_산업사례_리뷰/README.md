## 리뷰 원칙

원문 URL, 확인 날짜, 문서 발행 주체를 남기고, 직접 확인한 사실과 개인 해석을 분리합니다. 기업 내부 정보, 미공개 성능 데이터, 고객 정보를 넣지 않습니다.
