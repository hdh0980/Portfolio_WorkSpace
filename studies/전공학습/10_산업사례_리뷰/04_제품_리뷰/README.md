# 제품 리뷰

공개 제품 자료를 시스템 구조와 적용 조건 중심으로 비교하기 위한 하위 페이지입니다. 현재는 분류 구조만 있고, 특정 제품의 리뷰 본문이나 결론은 추가하지 않았습니다.

## 리뷰를 추가할 때 확인할 항목

- 제조사 공식 페이지·카탈로그·데이터시트의 URL과 확인 날짜
- 제품이 해결하는 문제와 시스템 내 역할
- 사양을 비교할 때의 동일 조건과 단위
- 공개 자료만으로 확인할 수 없는 항목과 추가 검증 필요 여부

제품 이미지는 설명을 위한 공개 예시로만 사용하며, 실제 업무 수행 제품이나 고객 정보를 나타내지 않습니다.
