# 전기전자 핵심기초

전기전자공학 전공 기초 다섯 과목을 단원별로 다시 정리한 노트입니다.
수학·물리 선수과목은 뺐고, 제어는 [제어시스템 설계](../02_제어시스템_설계/README.md)에
따로 정리했습니다.

## 학습 영역

| 순서 | 과목 | 핵심 학습 범위 |
|---:|---|---|
| 01 | [회로이론](./01_회로이론/) | 회로 법칙, 회로망 해석, 과도응답, 교류와 주파수응답 |
| 02 | [전자기학](./02_전자기학/) | 전계·자계, 물질 경계, 맥스웰 방정식, 전자파와 전송선 |
| 03 | [전자회로](./03_전자회로/) | 반도체 소자, 증폭기, 연산증폭기, 피드백과 발진 |
| 04 | [논리회로](./04_논리회로/) | 부울대수, 조합·순차논리, 상태기계, 메모리와 HDL 기초 |
| 05 | [신호와 시스템](./05_신호와_시스템/) | LTI 시스템, 컨볼루션, 변환 해석, 샘플링과 필터 기초 |

## 권장 학습 흐름

```text
회로이론
  ├─→ 전자기학
  ├─→ 전자회로
  ├─→ 논리회로
  └─→ 신호와 시스템
```

회로이론을 먼저 보고 나머지 과목은 병행해도 됩니다. 전자회로는 회로 해석을,
신호와 시스템은 함수·복소수·미적분을 쓸 줄 안다는 전제로 썼습니다.
