# 제어시스템 설계

전력변환기 제어를 하면서 다시 찾아본 내용을 모은 폴더다. 순서는 모델 → 루프 설계 →
DSP 구현 → 시험이다. 설계 기록 세 개는 UPS·ESS 업무 사례이고, 회로 정수·고객 사양·
calibration 값은 뺐다.
