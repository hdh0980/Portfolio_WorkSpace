# 제어시스템 설계

전력변환기 제어를 하면서 다시 찾아본 내용을 모은 폴더다.

| 번호 | 폴더 | 내용 |
|---:|---|---|
| 01 | [이론 노트](./01_이론_노트/) | 제어 기초 → PID → 주파수응답 → 디지털 구현 → 상태공간 → 고급제어 → 검증 체크리스트 (7개) |
| 02 | [PI·IP 비교 예제](./02_PI_IP_비교_예제/) | 1차 플랜트에서 PI와 IP 지령 응답 비교, MATLAB 코드와 결과 그림 |
| 03 | [전력전자 랩 화면](./03_전력전자_랩화면/) | 제어 알고리즘·DC-DC·PFC·DAB·SRDAB·LLC 학습 화면과 수식 |
| 04 | [참고자료](./04_참고자료/네이버_제어분야_글목록.md) | 이론 노트를 쓸 때 참고한 블로그 글 목록 |

이 내용을 실제 UPS·ESS 제어에 쓴 기록은 포트폴리오의 [UPS](../../../01_UPS_병렬운전_제어/)·[ESS](../../../02_ESS_계통연계_HILS_검증/) 프로젝트에 있다.
