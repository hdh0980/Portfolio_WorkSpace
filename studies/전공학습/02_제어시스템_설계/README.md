# 제어시스템 설계

전력변환기 제어를 다루면서 다시 찾아본 내용을 정리한 폴더다. 개념을 길게
나열하기보다, 실제 설계에서 자주 막히는 순서대로 남겼다. 모델을 잡고, 루프를
정한 뒤, DSP에 넣고, 시험으로 확인하는 흐름이다.

이론 노트는 전압·전류 제어루프를 검토할 때의 기준이고, 아래 설계 기록은 UPS와
ESS 업무에서 남긴 공개 가능한 범위의 사례다. 회로 정수, 고객 사양, calibration
값과 원본 파형은 넣지 않았다.
