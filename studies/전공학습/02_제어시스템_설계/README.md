# 제어시스템 설계

전력변환기 제어를 하면서 다시 찾아본 내용과 업무 설계 기록을 모은 폴더다.

| 번호 | 폴더 | 내용 |
|---:|---|---|
| 01 | [이론 노트](./01_이론_노트/) | 제어 기초 → PID → 주파수응답 → 디지털 구현 → 상태공간 → 고급제어 → 검증 체크리스트 (7개) |
| 02 | [PI·IP 비교 예제](./02_PI_IP_비교_예제/) | 1차 플랜트에서 PI와 IP 지령 응답 비교, MATLAB 코드와 결과 그림 |
| 03 | [전력전자 랩 화면](./03_전력전자_랩화면/) | 제어 알고리즘·DC-DC·PFC·DAB·SRDAB·LLC 학습 화면과 수식 |
| 04 | [업무 설계 기록](./04_업무_설계기록/) | 3레벨 UPS 출력전압 제어, UPS 병렬운전, ESS HILS 계통연계 검증 |
| 05 | [참고자료](./05_참고자료/네이버_제어분야_글목록.md) | 이론 노트를 쓸 때 참고한 블로그 글 목록 |

01 → 02 → 03은 공부한 순서이고, 04는 그 내용을 실제 UPS·ESS 제어에 쓴 기록이다.
업무 기록에서는 회로 정수·고객 사양·calibration 값을 뺐다.
