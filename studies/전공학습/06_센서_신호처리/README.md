# 센서·신호처리

이 폴더는 전력·제어 시스템에서 사용하는 측정값을 어떻게 얻고 처리하는지 정리하기 위한 학습 영역입니다. 현재는 자료를 담기 위한 인덱스만 있으며, 학습 본문은 아직 작성하지 않았습니다.

## 자료를 추가할 때의 구성

| 구분 | 기록할 내용 |
| --- | --- |
| 측정 대상 | 전압·전류·온도·속도 등 신호의 의미와 측정 범위 |
| 처리 과정 | 센싱, 신호 조절, 샘플링, 필터, 변환 과정 |
| 오차와 제한 | 대역폭, 노이즈, 지연, 분해능, 보정 조건 |
| 검증 | 기준 신호와 비교하는 계산·시뮬레이션·측정 방법 |

실제 하드웨어 회로, 보정값, 사내 측정 로그는 포함하지 않습니다.
